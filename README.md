# Research skills

Agent skills for survey and research methods: design a questionnaire and check it for bias, size the
sample, run Van Westendorp and MaxDiff, code open-ended answers, read NPS and PMF surveys, and turn a
discussion guide into an AI-moderated interview. They work in Claude Code, Claude.ai, Codex, Cursor, GitHub
Copilot and other agents that read `SKILL.md`.

Every skill works on your own files with no account. Where a study needs fielding, the last step shows how
to run it with QuestionPunk's MCP server; that step is optional.

> **Status: 0.1.0, early release.** The scripts are tested (528 tests) and their numbers were re-derived
> independently, including published worked examples. [Open an issue](../../issues) when something looks
> wrong.

## Install

All skills, into the agent you use:

```text
npx skills add questionpunk-labs/research-skills
```

One skill:

```text
npx skills add questionpunk-labs/research-skills --skill van-westendorp-analysis
```

Claude Code plugin marketplace:

```text
/plugin marketplace add questionpunk-labs/research-skills
/plugin install research-skills@research-skills
```

The marketplace also has one plugin per method group: `survey-design`, `pricing-research`,
`feedback-analysis` and `interviews`.

By hand: copy any folder under `skills/` into your agent's skills folder (`.claude/skills/`,
`.github/skills/` or `.agents/skills/`). Skills with a script need Python 3.9 or later and nothing else.

## How they chain

1. Decide: `survey-from-decision`
2. Write and check: `survey-bias-check`
3. Size: `survey-sample-size`
4. Field
5. Clean: `survey-data-cleaning`
6. Code open ends: `open-ended-coding`
7. Analyze: `nps-analysis`, `pmf-survey`, `van-westendorp-analysis`, `maxdiff-analysis`

## Run it on QuestionPunk (optional)

Skills that can field a study end with a short "Field it" section. It names the QuestionPunk MCP tools the
step would use (endpoint `https://app.questionpunk.com/api/v1`, OAuth sign-in). The agent asks before
creating, changing or publishing anything.

## How the scripts are tested

Skills that compute something ship a small Python script (3.9+, standard library only, no network) with
fixtures whose expected results were worked out independently. Each skill's `references/sources.md` cites
every formula and threshold. To check every skill and run its tests:

```text
node tools/validate.mjs --tests
```
